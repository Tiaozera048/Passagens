# Passagens Aéreas

Este repositório contém um formulário moderno para solicitar orçamentos de passagens aéreas, hospedagem e outros serviços de viagem. O objetivo é facilitar o planejamento da sua viagem dos sonhos, permitindo enviar uma solicitação personalizada e rápida.

## Acesse o Formulário

Você pode acessar o formulário diretamente pelo arquivo [Passagens.html](./Passagens.html).

Se o GitHub Pages estiver ativado, acesse a versão online:
```
https://{SEU_USUARIO}.github.io/{NOME_DO_REPOSITORIO}/Passagens.html
```
(Substitua `{SEU_USUARIO}` e `{NOME_DO_REPOSITORIO}` pelos dados do seu repositório.)

## Funcionalidades

- Solicitação de orçamento para diversos serviços (passagens, hospedagem, transfer, seguro, passeios, pacote completo);
- Seleção de datas, destinos, número de adultos e crianças;
- Escolha da faixa de orçamento e urgência;
- Envio direto para o WhatsApp da equipe responsável.

## Como usar

1. Abra o arquivo `Passagens.html` no navegador ou acesse a versão online pelo GitHub Pages.
2. Preencha os campos obrigatórios.
3. Selecione os serviços desejados.
4. Clique no botão “Solicitar via WhatsApp” para enviar sua solicitação.
